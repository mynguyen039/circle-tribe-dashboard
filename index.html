Kết nối Notion thông qua proxy server. Tokens bảo mật trong environment variables.
⚠️ Chạy trên Render: token tự động từ server. Chỉ cần nhập nếu dùng local.

DB IDs đã điền sẵn. Dữ liệu lưu trong sessionStorage trình duyệt.
Chat History
Tạo 1 database mới trong Notion → đặt tên Chat History → chỉ cần 1 cột Title → copy DB ID vào đây.
DB ID = chuỗi 32 ký tự trong URL: notion.so/xxxxxxxx?v=...
Nhập DB ID bên trên để xem lịch sử chat
👥 Team Chat Live Chưa bật
