Notion API chặn browser requests (CORS). Cần một proxy nhỏ ở giữa. Chọn 1 trong 2 cách bên dưới:
⚡ Cách A — Cloudflare Worker (khuyến nghị)
1. Vào workers.cloudflare.com → đăng ký free
2. Create Worker → xoá code mẫu → paste Worker Code từ hướng dẫn
3. Deploy → copy URL dạng https://xxx.workers.dev
4. Paste URL vào ô Proxy URL bên dưới
🐍 Cách B — Python Local (không cần internet)
1. Lưu file notion_proxy.py → điền token vào
2. Chạy: python notion_proxy.py
3. Proxy URL = http://localhost:8787
DB IDs đã điền sẵn. Dữ liệu lưu trong sessionStorage — không gửi đi đâu ngoài Notion qua proxy của bạn.
